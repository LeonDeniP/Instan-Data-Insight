# 🚀 Instant Data Insight

Dashboard analitik cerdas yang dirancang untuk memproses dataset besar (CSV) secara otomatis, memberikan ringkasan statistik deskriptif, dan menghasilkan insight bisnis menggunakan AI (Google Gemini).

## 🛠️ Tech Stack
- **Frontend:** Vue.js 3, Tailwind CSS, Chart.js.
- **Backend:** FastAPI (Python), Pandas, SQLAlchemy (MySQL).
- **AI Integration:** Google Gemini API.
- **Report Generation:** ReportLab (PDF Export).

## 📋 Fitur Utama
- **Automated Analysis:** Unggah file CSV dan dapatkan ringkasan statistik dalam hitungan detik.
- **AI-Powered Insights:** Analisis mendalam berbasis peran (Chief Data Scientist) untuk *executive briefing*.
- **Data Visualization:** Visualisasi otomatis data Anda menggunakan Chart.js.
- **History Tracking:** Simpan dan kelola riwayat analisis langsung di database MySQL.
- **PDF Export:** Unduh laporan hasil analisis dalam format PDF yang rapi.

## 🚀 Instalasi & Cara Menjalankan

### Persiapan Environment
1. Pastikan Python 3.11+ dan Node.js sudah terinstal.
2. Buat database MySQL baru dengan nama `db_instant_insight`.
